# ROADMAP

This is the process I will reuse when starting a new assignment.

1. Define intent and constraints.
2. Sketch the system in words before coding.
3. Identify the signal, parameter, and dominant behavior.
4. Build the smallest working version.
5. Test the system in the browser.
6. Check whether the behavior is understandable without explanation.
7. Iterate through visible tests.
8. Record important changes in the process log.
9. Take screenshots of major milestones.
10. Polish only after the meaning is legible.
11. Update the README so another person can understand the project.
12. Deploy the finished build and test the public link.
